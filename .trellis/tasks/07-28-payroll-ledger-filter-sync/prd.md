# 工资台账筛选与汇总联动

## Goal

让工资台账的汇总区、筛选区和列表采用项目内其他工作台页面的统一呈现方式，并支持按工资发放主体筛选。

## Requirements

- 调整截图中左侧汇总区和右侧列表区的视觉表现，复用设备、班组、合作单位等现有工作台模式，不保留与参考页面不一致的独立卡片观感。
- 在顶部筛选栏增加一个“发放主体”下拉框。
- “发放主体”选项包含全部发放主体、当前可用的各工资发放公司，以及“私人转账（个人垫付）”。
- 选择公司时，只显示该公司账户发放的工资批次；选择私人转账时，只显示资金来源为个人垫付的工资批次。
- 搜索、状态和发放主体筛选可以叠加使用，并通过 URL 查询参数保持状态。
- 左侧批次数、实际发放、员工发放、班组发放及各状态计数必须与顶部当前筛选条件同步。
- 左侧状态快捷筛选、清除状态、新建和编辑返回链接需要保留当前搜索和发放主体条件。
- 修复发放日期单元格中的长账户名称越过列边界、与人数列视觉重叠的问题。
- 修复“列管理”菜单被工资列表工具栏裁切、点击后看不到菜单内容的问题。
- 工资批次列表的人数列除总人数外，必须同时显示员工人数和班组人员人数。
- 查看工资批次时，金额构成区域必须显示员工人数和班组人员人数，并提供“查看详细名单”入口。
- 详细名单使用二级弹窗，按自有员工、施工班组人员分区显示姓名、所属班组（适用时）和实际金额。
- 不修改工资批次数据结构、数据库 schema、公共应用层合同或工资入账规则。

## Acceptance Criteria

- [ ] 工资台账左右区域与现有工作台页面的边界、背景、间距和工具栏风格一致，不出现截图中的独立大卡片观感。
- [ ] 顶部出现“发放主体”下拉框，并包含公司列表和“私人转账（个人垫付）”选项。
- [ ] 选择任一公司后，列表中仅保留该公司账户发放的批次。
- [ ] 选择“私人转账（个人垫付）”后，列表中仅保留个人垫付资金来源的批次。
- [ ] 搜索、状态、发放主体任意组合时，左侧汇总金额、批次数及状态计数与列表使用相同结果集。
- [ ] 左侧状态链接切换后不丢失搜索和发放主体条件。
- [ ] 发放日期和账户名称始终限制在日期列内，长文本自动换行或截断，不覆盖人数列。
- [ ] 点击“列管理”后菜单完整可见，可勾选列并确认生效。
- [ ] 人数列显示总人数、员工人数和班组人员人数，三项与该批次实际明细一致。
- [ ] 查看弹窗显示人数分项，并能打开二级详细名单弹窗。
- [ ] 二级名单按员工和班组分区显示完整姓名；班组人员显示班组名称，各人员显示实际金额。
- [ ] 页面模型定向测试、页面资产测试和 Release 构建通过。
- [ ] 桌面浏览器中布局无重叠，筛选提交和左侧状态联动符合预期，控制台无新增错误。

## Notes

- 本任务按用户要求创建 Trellis 任务。
- “私人转账”沿用现有领域值 `PayrollFundingSource.PersonalAdvance`，界面文案补充“个人垫付”以避免与业务含义脱节。
