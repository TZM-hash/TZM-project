# 全站列管理保存与字体清晰度优化

## Goal

让所有使用共享数据工作台的列表页记住用户最后一次列管理设置，并消除鼠标悬停到数据面板时整块文字变模糊的问题；不改变现有页面布局、业务数据或既有项目负责人等未提交改动。

## Requirements

- 列管理设置按当前浏览器/当前电脑保存，至少包括列显隐和列顺序；现有行距、分页大小的本地记忆继续保留。
- 用户重新打开同一页面和同一列表时，优先恢复本地最后一次列管理设置；服务器保存视图只在没有本地设置时作为初始值，不得覆盖本地最后一次设置。
- 恢复设置时要兼容新增、删除或固定列：固定列仍不可隐藏，未知旧列被忽略，新列按默认顺序补入。
- 点击“恢复默认”后，用户点击“确认”才保存默认列配置；不能出现只打开菜单或取消操作就覆盖已保存配置的情况。
- 鼠标悬停在项目管理、项目详情及其他含表格/大量文字的面板时，不对承载正文的整块面板进行 `transform` 位移或缩放；可以保留颜色、边框、阴影等不影响文字栅格化的悬停反馈。
- 保持整体布局、现有字号设置、主题颜色和响应式行为不变，不让文字溢出；动效设置仍可用于不承载正文的装饰性卡片。

## Acceptance Criteria

- [ ] 共享列管理页的本地列设置在刷新和重新进入页面后恢复，且服务器保存视图不会覆盖本地最后一次设置。
- [ ] 固定列、新增列、失效列和“恢复默认/取消”路径均有自动化回归测试。
- [ ] 悬停含数据面板时不再触发面板级 `transform`，相关 CSS 资产测试覆盖两种动效样式。
- [ ] 目标 .NET 测试通过，Web 项目构建通过，正确的本地服务启动后健康检查通过。
- [ ] 通过浏览器实际检查项目管理列表页：鼠标移入/移出页面和表格区域，文字保持清晰，布局无跳动或溢出。
