# 施工班组工作台功能级对齐设计

## 目标

将施工班组列表页按合作单位页的结构、财务数据和弹窗交互重制为统一工作台，使班组主档、联系人、项目参与、应收、应付和开票信息与合作单位页使用同一种信息层级，同时保留现有人员名册和工资发放详情页作为班组专属业务入口。

## 范围与边界

- 列表页对齐合作单位页的页面头部、左右工作台、汇总筛选、数据工具栏、固定列宽表格、Mac 风格查看与编辑弹窗以及语义操作按钮。
- 新增、编辑和复制继续写入合作单位主档，但角色固定为 `ConstructionCrew`。
- 人员名册、人员新增与转组、工资发放历史继续由 `/Crews/Details` 承载；列表页通过锚点进入对应区域。
- 财务三列和财务弹窗复用合作单位页现有中央账本汇总口径，不重新计算或复制财务数据。
- 不修改数据库结构、公共 DTO、共享服务契约或工资与中央账本口径。
- 不把人员名册或工资明细嵌入列表页弹窗。

## 页面结构

页面头部显示“施工班组”和简短说明，管理角色可见“新增施工班组”按钮。

主体使用与合作单位页一致的两列工作台：

- 左侧约 220px，显示班组总数、启用、停用和当前人员总数；下方按专业分类展示数量并提供筛选。
- 右侧顶部显示当前筛选范围，工具栏依次提供专业、全字段搜索和状态筛选，并保留列管理与密度切换。
- 900px 以下改为上下排列，表格只在自身容器内横向滚动，不撑宽页面。

表格列为：班组、角色 / 专业、主要联系人、参与项目、应收、应付、开票、状态、操作。除“班组”名称和额外的人员入口外，单元格结构、财务三行数据、进度条、颜色状态和列宽均与合作单位页一致。班组角色固定显示“施工班组”，专业显示在第二行。

## 操作与弹窗

- 查看：使用合作单位详情弹窗的结构和数据层级，显示班组主档、角色 / 专业、主要联系人、项目数、状态和备注；底部保留人员与财务入口。
- 编辑：使用合作单位编辑弹窗的四区布局，维护编号、全称、简称、信用代码、专业、负责人、联系电话、备注、状态和修改原因；角色以只读方式固定为施工班组。
- 复制：复用编辑弹窗，生成编号与名称副本，清空信用代码和联系人，角色仍固定为施工班组。
- 人员：进入 `/Crews/Details?id=<id>#crew-roster`。
- 财务：打开与合作单位页相同的财务汇总弹窗，展示 KPI、进度图和应收 / 应付明细；弹窗底部可进入班组详情页财务区域。

详情页只增加稳定锚点，不重排人员和工资业务表格。

## 数据与权限

页面模型使用现有 `IConstructionCrewService`、`IBusinessPartnerService`、`ICentralLedgerQueryService` 和 `ApplicationDbContext`：

- 班组服务提供搜索、人员数和启停状态；人员数继续用于左侧概览。
- 合作单位服务提供完整主档、联系人、备注和并发戳，用于弹窗查看及保存。
- 中央账本查询服务按当前用户权限批量返回与合作单位页相同的 `PartnerLedgerSummaryDto`，用于应收、应付、开票列和财务弹窗。
- 页面按班组 ID 合并两类数据，并在页面模型中形成专用工作台行模型，不扩展公共 DTO。
- 全量班组数据用于汇总和专业分布；搜索结果再叠加专业与状态筛选。

新增、编辑权限保持为系统管理员、应用管理员和项目经理。财务入口保持为系统管理员、应用管理员和财务角色。敏感数据读取继续遵守现有脱敏规则。

## 保存与错误处理

新增和复制调用现有合作单位创建接口，写入单一施工班组角色。编辑调用现有更新接口，保留并发戳、状态、修改原因和审计记录。

模型验证、业务规则或并发校验失败时，重新加载工作台并自动打开编辑弹窗显示错误；权限不足直接返回禁止访问。保存成功后带回当前搜索、专业和状态筛选。

## 前端实现

页面级 `crew-workspace.js` 负责筛选自动提交、弹窗开关、详情填充、财务 KPI / 图表填充，以及新增、编辑和复制表单初始化。财务计算和零值弱化逻辑与 `partner-workspace.js` 保持一致。

样式集中写入现有 `pages.css`，使用 `crew-workspace-*` 命名并复用现有颜色、间距、按钮和弹窗基础组件，不重构合作单位页或全局工作台组件。

## 验证

- 页面契约测试覆盖左右工作台、汇总、筛选、列、弹窗、五类操作、权限入口和详情锚点。
- 页面模型契约覆盖中央账本批量汇总、财务可见权限、全量汇总、搜索、专业和状态筛选，以及新增、编辑、复制所需的保存路径。
- 定向运行施工班组、合作单位、数据工作台和响应式测试。
- Release 构建必须为零错误、零警告。
- 浏览器在截图同级桌面宽度、1366px 和 390px 下检查长文本、金额、按钮、弹窗和横向溢出；控制台不得出现错误。
