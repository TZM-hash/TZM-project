# 数据往返导入导出工作台设计

**日期：** 2026-08-03
**状态：** 待用户审阅
**适用范围：** 现有 Excel 导入导出、项目工作簿和批量业务数据交换

## 1. 目标

把现有混合在一个页面中的导出、项目工作簿、批量导入和历史记录，重组为清晰的“数据往返工作台”，优先解决以下主流程：

```text
选择数据范围 → 导出 Excel → 在 Excel 中补充/修改 → 上传回系统
→ 自动识别 → 差异预览 → 冲突校验 → 整批确认 → 查看结果
```

用户不需要理解数据库字段或内部表名，也不需要手工拼接 ZIP。列表页仍然可以快捷导出，但所有批量交换都进入同一套规则、预览和任务记录。

## 2. 已确认的业务规则

- 主流程是“系统导出后补充/修改，再导入更新”。
- Excel 空白单元格默认表示“不修改原值”。
- 如果记录在导出后被其他人修改，导入时标记并发冲突，不覆盖系统数据。
- 一份文件中任何一行存在错误、关联缺失、权限问题或并发冲突，整批都不写入。
- 普通导出默认生成一个 Excel；只有勾选附件时才生成 ZIP。
- 不允许通过 Excel 物理删除业务记录。
- 需要清空可空字段时，使用明确的“清空”标记，不能把空白同时解释为清空。

## 3. 页面信息架构

### 3.1 三个独立视图

将当前 `/DataExchange` 拆为三个清晰视图：

1. **导出数据**：选择模块、筛选范围、字段、文件结构和附件，生成 Excel。
2. **导入数据**：上传文件、识别来源、确认映射、预览差异、确认整批写入。
3. **任务记录**：统一显示导出任务和导入批次，支持下载结果、原文件和错误报告。

保留 `/DataExchange` 作为兼容入口，默认重定向到“导出数据”。现有列表页的导出按钮继续保留，并携带来源页面、筛选条件、排序和选中记录进入导出视图。

### 3.2 导出视图

导出页面按连续步骤排列，不再把字段目录、模板保存和项目工作簿表单堆在同一屏：

1. **来源范围**：显示来源页面和当前筛选摘要；可切换当前筛选、选中记录、当前授权全量。
2. **业务模块**：选择一个或多个模块。项目工作簿作为“项目管理”模块下的标准多表结构，不再使用另一套入口文案。
3. **字段和顺序**：字段按基础资料、关联信息、金额、日期、状态、备注、系统追踪分组；支持搜索、分组全选、恢复默认和拖动调整顺序。
4. **文件选项**：默认 Excel；选择附件后自动切换为 ZIP，并显示附件数量、大小和预计文件结构。
5. **生成前确认**：显示预计记录数、敏感字段提示、筛选摘要、文件格式和导出按钮。

导出成功后，页面显示任务编号和下载入口；用户可以继续留在当前页，也可以打开任务记录查看。

### 3.3 导入视图

导入采用单向分步向导，每一步只显示当前需要的操作：

1. **选择来源**：系统导出文件、空白模板、任意 Excel 或含附件 ZIP。上传后自动识别文件类型、数据集、版本和校验摘要。
2. **确认映射**：系统导出文件直接使用标准映射；任意 Excel 使用精确表头、别名和历史映射自动匹配，用户只调整无法确认的列。
3. **预览差异**：按数据集和工作表显示新增、更新、未变化、跳过和错误数量；可筛选错误行、并发冲突和关联问题。
4. **确认整批**：显示“本批次不会部分写入”的明确提示，只有无错误、无冲突时才允许确认。
5. **结果**：显示成功摘要，或显示失败原因并提供错误 Excel 下载；原始文件、映射和校验摘要进入任务记录。

### 3.4 任务记录视图

任务记录统一展示导入和导出，默认按最新时间在前，并提供独立的 20/50/100 条分页选择。支持按方向、模块、状态、操作人、时间范围和批次号筛选。

每条记录显示：

- 批次号、方向、模块和来源页面；
- 操作人、创建时间、完成时间和当前状态；
- 文件名、文件摘要、行数、新增/更新/未变化/错误数量；
- 关联的导出批次（如果该导入来自系统导出文件）；
- 原始文件、结果文件和错误报告的授权下载按钮。

## 4. Excel 往返文件契约

### 4.1 标准工作簿结构

普通导出使用一个 Excel 文件，包含：

- `目录`：模块、工作表、记录数和说明链接；
- `数据说明`：字段含义、必填规则、枚举值、关联键和敏感字段提示；
- 一个或多个业务工作表；
- 每个业务工作表的字段顺序与导出时的字段选择一致。

含附件时，外层改为 ZIP，包含标准工作簿、`manifest.json`、`checksums.sha256` 和安全的附件相对路径。没有附件时不强制 ZIP。

### 4.2 系统控制字段

系统导出的每个可回导工作表保留隐藏并保护的控制列：

- `_record_id`：系统记录 ID；
- `_business_key`：稳定业务编号；
- `_row_version`：导出时的并发版本；
- `_dataset_key` 和 `_dataset_version`：目标数据集及版本；
- `_export_batch_id`：来源导出批次号。

控制列不参与普通字段选择，不允许用户修改。追加新行时控制列为空，系统按新增模式校验必填字段和业务编号。

### 4.3 空白和清空语义

- 普通空白单元格：不修改原值；
- 明确的 `【清空】` 标记：请求清空可空字段，预览中单独显示；
- 必填字段不允许清空；
- 计算字段、系统字段和只读字段不允许导入覆盖。

## 5. 导入识别、校验和事务

### 5.1 记录定位

按以下优先级定位原记录：

1. `_record_id`；
2. 稳定业务编号；
3. 新增行的业务编号或必填组合键。

系统导出文件中如果控制字段被删除、篡改或与数据集不一致，预览直接报错，不静默降级到模糊匹配。

### 5.2 校验顺序

依次校验文件格式、工作表、数据集版本、字段映射、必填项、类型、长度、日期、金额、枚举、业务编号重复、关联记录、权限范围、并发版本和模块业务规则。含附件时额外校验相对路径、路径穿越、扩展名、大小和 SHA-256。

### 5.3 整批原子性

预览阶段只保存原始文件、映射和错误，不写业务数据。确认阶段在一个数据库事务中按依赖顺序执行；任意错误、关联缺失、权限不足、并发冲突或附件校验失败都阻止整批写入。

导入成功后重新读取受影响的列表和汇总，确保页面显示与导入结果一致。导入不会物理删除记录，停用、作废和结束状态继续使用现有业务字段和服务规则。

### 5.4 错误报告

错误报告单独生成 Excel，包含：原始文件、工作表、行号、来源列、目标字段、原始值、错误原因和修正建议。错误报告通过授权下载端点提供，不暴露服务器物理路径。

## 6. 后端边界

保留现有模块导出器和导入器，不让页面直接访问 EF 实体。增加统一的数据交换目录和批次协调层：

- 数据集目录：模块、字段、版本、权限、关联、依赖和校验规则；
- 工作簿/ZIP 构建器：目录、说明、控制列、链接、附件清单和校验和；
- 导入协调器：来源识别、映射、预览、差异、冲突和整批确认；
- 任务查询服务：统一投影现有导出任务和导入批次，支持分页、筛选和下载授权。

现有 `IExportService`、`IImportService` 和项目工作簿服务继续作为模块适配器。现有导入批次表继续保存原始文件和错误明细；补充来源导出批次号、数据集版本、源文件 SHA-256、来源类型和错误报告信息，使“导出—回导”能够关联追踪。

大文件暂时沿用任务记录和可恢复的请求状态；超过配置阈值后再切换后台队列，不改变页面契约。

## 7. 权限和安全

- 导出范围始终先应用当前用户权限，再执行查询；
- 敏感字段按权限自动脱敏；
- 全量导出、含附件导出和批量导入确认仅开放给授权角色；
- 文件下载必须校验当前用户是否为任务所有者或具备管理员权限；
- 原始导入文件和导出结果保留 SHA-256，避免错误文件被替换后继续确认；
- 不允许通过 Excel 访问密码、令牌、连接字符串、审计日志或技术内部数据。

## 8. 分阶段实施

### 第一阶段：主流程和页面拆分

- 将当前单页拆分为导出、导入、任务记录三个视图；
- 统一来源页面筛选摘要和字段选择；
- 给系统导出文件加入控制字段、版本和批次号；
- 实现系统导出文件识别、空白不修改、并发冲突和整批确认；
- 任务记录加入导入批次、分页、错误报告下载。

### 第二阶段：模板和多模块交换

- 完善个人/共享字段模板和映射模板；
- 统一普通模块与项目工作簿的目录、说明和预览样式；
- 支持一个 Excel 多模块工作表和含附件 ZIP；
- 增加跨表链接、附件清单和校验和回读测试。

### 第三阶段：大文件和全量覆盖

- 代表性大文件切换后台任务；
- 补齐仍未登记的可维护数据集；
- 在统一财务模型稳定后接入最终财务数据集，不为将被替换的旧结构建立长期模板；
- 增加全字段导出—回导测试和历史任务清理策略。

## 9. 验收标准

- 从任意列表页按当前筛选导出后，回到导入向导能自动识别模块和映射；
- 只补充部分字段时，未填写字段保持原值；
- 追加新行可以新增，原有行按 ID/业务编号更新；
- 导出后系统记录被修改时，整批被并发冲突阻止；
- 任意一行错误时整批不写入，并能下载错误 Excel；
- 普通导出直接得到 Excel，含附件时得到 ZIP；
- 任务记录按最新在前，支持 20/50/100 条独立分页；
- 无权限用户无法导出未授权数据、读取敏感字段或下载他人任务文件；
- 现有标准 Excel、项目工作簿和旧版任意 Excel 映射流程保持兼容；
- 导出、预览、确认和结果页面在桌面与窄屏下均不出现横向溢出或表单混堆。

## 10. 暂不纳入本轮

- 不把 Excel 替代数据库备份；
- 不通过导入实现物理删除；
- 不在本轮重写所有业务模块的内部查询服务；
- 不在统一财务模型稳定前固化旧财务表的长期双向模板；
- 不强制用户使用 ZIP 进行普通数据交换。
