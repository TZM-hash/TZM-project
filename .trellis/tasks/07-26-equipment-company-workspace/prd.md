# 设备管理按公司归类与合格证附件改造

## Goal

将设备管理改造成按自有公司归类的工作台，并补齐设备权属、合格证附件和跨模块复用能力。

## Requirements

- 设备管理总览参考“自有公司”页面重新排版，保持现有后台管理界面的视觉与交互一致性。
- 支持“全部公司”和指定自有公司筛选；设备以管理公司为主要归类维度。
- 左侧显示当前筛选公司的设备汇总信息，右侧显示该范围内的设备列表。
- 右侧列表中的新增、查看、编辑等设备维护操作均在当前页面弹窗内完成，不跳转页面。
- 新增和编辑表单必须完整展示设备业务字段，并从自有公司数据源选择管理公司。
- 设备需明确区分“自有”和“租赁”：自有设备记录产权公司，租赁设备记录出租方；两类设备都关联一个管理公司。
- 每台设备维护一份当前有效合格证，支持填写证书编号、发证日期、有效期并上传附件；替换时更新当前记录，不保留历史版本。
- 设备继续使用统一设备领域数据，项目管理等其他模块可读取同一批设备，不建立页面私有副本。
- 保持现有设备和项目数据兼容，数据库变更通过 EF Core migration 完成。

## Constraints

- 不覆盖或回退工作区中已有的“自有公司”未提交修改。
- 设备管理公司必须来自自有公司（LegalEntity）数据，不允许手工输入 GUID。
- 页面列表在常见桌面宽度下应能直接浏览核心字段，避免依赖横向滚动条完成主要操作。
- 文件上传沿用项目现有附件存储与下载安全约束；若现有项目没有可复用能力，则新增边界清晰的设备附件服务。

## Acceptance Criteria

- [ ] 进入设备管理页即可看到公司筛选、左侧设备总览和右侧设备列表。
- [ ] 选择“全部公司”显示全部设备；选择某公司后，汇总和列表同步只显示该公司管理的设备。
- [ ] 自有与租赁设备均能选择管理公司；自有设备可选择产权公司，租赁设备可选择出租方。
- [ ] 新增、查看和编辑设备均使用弹窗，保存成功后当前工作台就地刷新，不发生整页导航。
- [ ] 新增和编辑弹窗完整显示并保存当前设备领域支持的字段及本次新增字段。
- [ ] 每台设备可上传、查看/下载、替换和删除一份当前有效合格证附件，并显示证书编号、发证日期和有效期。
- [ ] 项目管理读取设备时可使用本次维护后的设备数据，并能识别管理公司与权属类型。
- [ ] 数据库迁移可应用；设备领域、Web 页面和项目设备相关定向测试通过。
- [ ] 在桌面浏览器中验证布局、弹窗、筛选、附件和项目设备读取流程，无明显溢出或遮挡。
