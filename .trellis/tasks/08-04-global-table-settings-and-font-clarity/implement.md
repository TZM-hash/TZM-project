# 全站列管理保存与字体清晰度优化实施计划

## 目标

修复共享列管理本地设置被服务器视图覆盖的问题，并移除数据面板悬停时导致文字发虚的面板级变换。

## 执行顺序

1. 在 `DataWorkbenchAssetTests` 和 `UiEffectsAssetTests` 中先加入失败回归断言，并使用项目内 `dotnet.ps1 test` 确认失败原因是功能缺失。
2. 在 `_DataWorkbench.cshtml` 增加当前显式保存视图标记，在 `data-table.js` 实现普通进入本地列优先、显式保存视图服务器列优先并写回本地。
3. 在 `themes.css` 拆分指标卡与面板悬停规则，保留指标卡动效、移除 `.panel:hover` 的 `transform`。
4. 运行定向测试、完整测试、Release 构建、JavaScript 语法检查和 `git diff --check`。
5. 从 `EngineeringManager` 目录用 `scripts/start-local-web.ps1` 重启 `http://127.0.0.1:5075`，检查健康端点并进行浏览器运行态验收。

## 验收标准

- 本地列顺序和显隐在刷新/重新进入页面后恢复；服务器视图不覆盖普通进入时的本地最后设置。
- 显式选择服务器保存视图仍可生效，并成为后续本地最后设置。
- 鼠标悬停数据面板时正文文字保持清晰，指标卡动效仍存在，页面布局不跳动、不溢出。
- 目标测试和完整测试通过，Release 构建通过，服务 `/health/live` 与 `/health/ready` 返回 200。

## 变更边界

仅允许修改共享工作台 Razor、数据表格 JavaScript、主题 CSS、对应 Web 资产测试和本任务文档；保留工作区中其他既有未提交改动，不做数据库、依赖、配置、历史或远程操作。
