# 中央账本外部与内部账本工作台设计

本设计文档记录 2026-07-31 已确认的中央账本工作台改造方案。设计依据是现有员工管理与工资台账页面的工作台结构，并延续 `2026-07-19-central-ledger-multi-entry-design.md`、`2026-07-23-employee-management-workspace-design.md` 中的财务与 UI 边界。

## 已确认方案

外部账本、内部账本继续分开；每页使用左右工作台；业务标签是真实标签页；新增/编辑使用统一大弹窗；详情使用分区大弹窗；资金和发票支持待分摊/部分分摊；来源记录只读；已分摊/已对账/已关账记录锁定核心字段；删除需要原因并保留审计。

## 页面与业务区

外部账本标签为总览、应收、应付、收款、付款、销项发票、进项发票、扣款、待分摊、异常、工资付款、年度账、对账、修改记录。内部账本标签为总览、内部应收、内部应付、内部转账、内部发票、待分摊、年度账、对账、修改记录。所有标签保留公共筛选参数并可从左侧指标卡反向联动。

左侧常驻六项指标：应收未收、应付未付、本年收款/转入、本年付款/转出、待分摊、异常。总览区显示完整中央账本指标。金额色遵循员工/工资台账的固定语义色，异常和待分摊必须可被一眼识别。

## 数据与安全

查询层扩展安全投影 DTO，避免把 EF 实体或循环导航序列化到页面。详情通过当前账本页面的 GET handler 拉取，并受现有 `CentralLedgerActor` 范围校验。更新只作用于 `LedgerSourceType.CentralLedger` 的直接记录；来源模块记录从中央账本只读并跳转来源。分摊必须复用既有范围/方向/公司/往来单位验证。

## 验收重点

页面必须不再是普通面板堆叠或指向同一张表的伪标签；所有记录类型均有相应列表/空状态/操作列；详情、录入、删除、来源、分摊和审计交互保持工作台风格；财务计算、权限、并发和单一事实源不变。
