# 人员管理列表与薪资列设计

## 目标

内部人员和外部人员列表统一采用项目管理页的工作台规则：列管理可排序、可显隐并自动保存，导出支持勾选人员或当前筛选结果；同时将员工年度总账中的薪资及相关往来作为可选列。

## 设计

- 两个页面分别使用 `personnel-internal` 和 `personnel-external` 工作台键，避免内部、外部人员的列偏好互相覆盖。
- 列表字段拆成独立列：姓名、人员编号、电话、类型、岗位、公司/单位、部门、项目、班组、状态、操作，以及年度薪资列。
- 姓名和操作列固定显示；人员编号在列表中限制视觉宽度并对超长值省略，完整编号通过悬浮提示和导出保留，历史数据不截断、不改写。
- 表格采用固定布局和内部横向滚动；长名称使用受控换行或省略，操作按钮使用不换行的 flex 布局。
- 年度薪资列沿用员工业务档案当前业务年度及 `EmployeeAnnualLedgerSummary` 口径：往年结转、工资应付、报销应付、其他应付、调整金额、本年应发合计、已发合计、未发合计、当前余额、结算进度、超付状态、罚款扣减。默认隐藏，用户可在列管理中勾选。
- 没有员工业务档案的外部人员不显示虚构的工资金额，薪资列显示空值；导出对应单元格为空。
- 导出列同时支持当前列管理结果和独立的个人导出列选择，独立选择使用现有 `ISavedDataViewService` 保存。

## 数据流与安全

页面按当前筛选重新调用人员服务，服务端再将手动勾选的人员 ID 与授权筛选结果求交集；导出不会信任客户端提交的人员范围或列键。列键使用固定白名单，导出服务只输出允许的字段。

## 验收

- 内部、外部页面均可打开列管理并保存显隐/顺序，刷新后恢复。
- 所有人员资料不再跨列串行，操作始终一行显示；超长编号不会撑开类型、岗位等列。
- 薪资列默认不占用表格空间，勾选后正确显示当前业务年度数据。
- 导出支持选择人员、当前筛选全部人员和列选择；导出结果与当前授权范围一致。
- 定向测试、完整测试、构建和服务健康检查通过。
