# 人员管理筛选栏单行布局设计

## 目标

将内部人员和外部人员列表页的筛选区从纵向堆叠改为桌面端单行工具栏，减少首屏占用高度，接近项目管理页的紧凑筛选样式。

## 范围

- 调整 `Personnel/Internal/Index.cshtml` 和 `Personnel/External/Index.cshtml` 共用的筛选表单样式。
- 保留搜索、公司/单位、班组、部门、人员类型、状态、归属日期、筛选和重置全部控件及现有字段名。
- 不修改人员查询参数、服务调用、数据模型或筛选结果。

## 方案

为 `.personnel-filter-bar` 增加页面专属 Grid 布局。桌面端将七个筛选字段和操作按钮放在同一行，字段标签仍显示在控件上方，控件高度、内边距和间距适当压缩。筛选操作区保持按钮并排显示。

在较窄视口下，筛选区自动降为多列再到单列，保证控件具有可用宽度，不产生页面级横向溢出。该响应式降级只改变排列，不隐藏或删除筛选项。

## 验证

- 页面源码测试确认两个页面均使用专属筛选类，并保留全部查询字段。
- CSS 回归测试确认桌面 Grid、操作区单行和窄屏降级规则存在。
- 运行人员页面定向测试及完整测试，确认筛选参数传递不变。
