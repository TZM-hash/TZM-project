# 圆润柔光外观模式设计

**日期：** 2026-08-03
**状态：** 待用户最终审阅
**适用范围：** EngineeringManager 全部 Web 页面、共享组件和响应式布局

## 1. 目标

在保留现有界面风格的前提下，新增一套可切换的“圆润柔光”外观模式。该模式参考用户提供的视觉图片，重点提升卡片、弹窗、控件、按钮、菜单和导航的圆润度、层次感与柔和感，但不复制图片中的具体业务布局。

外观模式与颜色主题相互独立，可与默认、清透玻璃、薰衣草奶油及后续新增颜色主题自由组合。

## 2. 已确认选择

- 采用独立外观模式，不新增一套绑定颜色的完整主题。
- 提供“经典紧凑”和“圆润柔光”两个选项。
- 圆润程度为明显圆润：卡片约 18–24px、弹窗约 22–28px、按钮和输入控件约 12–16px。
- 切换入口只放在系统设置页，不增加顶部快捷切换按钮。
- 经典模式完整保留当前显示效果。

## 3. 架构

### 3.1 独立外观维度

在现有全局显示设置中增加 `AppearanceStyle`，只允许以下值：

- `Classic`：沿用当前组件圆角、阴影和控件尺寸。
- `RoundedSoft`：启用圆润柔光外观令牌和兼容样式。

服务端渲染页面时在 `body` 输出外观类：

```text
appearance-classic
appearance-rounded-soft
```

颜色主题类继续独立输出，例如：

```text
theme-lavender-cream appearance-rounded-soft
```

不得通过复制整套主题 CSS 实现组合，避免主题数量与外观数量相乘。

### 3.2 外观令牌

在全局主题样式中增加以下语义令牌，具体数值可在实施阶段按现有尺寸微调：

- 页面和大型容器圆角；
- 普通卡片圆角；
- 弹窗、抽屉和浮层圆角；
- 输入控件和按钮圆角；
- 小型菜单和紧凑控件圆角；
- 卡片柔光阴影；
- 浮层柔光阴影；
- 柔和高光边框；
- 控件聚焦光晕。

共享组件优先使用语义令牌。页面中已有写死圆角值只在圆润模式下通过针对性兼容选择器覆盖，不进行与本功能无关的大规模重构。

## 4. UI 覆盖范围

### 4.1 卡片和页面容器

覆盖面板、统计卡片、表单分区、数据工作台、设置选项卡、概览卡片、详情卡片、导入导出卡片和认证卡片。圆润模式使用 18–24px 圆角、柔和扩散阴影和轻微高光边框。

### 4.2 弹窗和浮层

覆盖原生 `dialog`、高级筛选弹窗、快速编辑弹窗、冲突提示、下拉菜单、列管理菜单、项目导出菜单、提示浮层和 Toast。桌面端使用 22–28px 圆角与更柔和的浮层阴影。

移动端需要保持可用性：全屏或贴边编辑弹窗允许降低或移除边缘圆角，避免占用有效空间或产生滚动缝隙。

### 4.3 表单控件和按钮

覆盖按钮、输入框、选择框、文本域、分页跳转、排序选择、每页条数选择、日期控件、文件选择、行内编辑和筛选控件。普通控件使用 12–16px 圆角；标签、状态和筛选条件继续使用胶囊形。

危险、警告、成功、禁用和焦点状态必须维持足够的颜色对比与清晰边界。

### 4.4 表格

表格外层容器、表头边界和首尾可见区域应用圆润处理。数据单元格不逐格卡片化，以保持财务、项目和员工数据的对齐效率与信息密度。

### 4.5 导航与布局

覆盖侧边栏、顶部栏、导航项、子菜单和当前选中态。圆润模式增加柔和选中背景和轻度光晕，但不改变现有导航宽度、页面结构、表格列宽和业务信息顺序。

## 5. 设置页面

在现有主题、字体和动画设置附近增加“界面外观”区块，使用两张预览卡展示：

1. 经典紧凑：当前卡片、按钮和输入框形态；
2. 圆润柔光：明显大圆角、柔光卡片、圆润按钮和弹窗预览。

选择结果通过现有全局显示设置提交流程保存。非法值、空值和旧数据库记录统一回退为 `Classic`，保证升级兼容。

## 6. 加载与状态一致性

- 服务端是外观设置的最终来源。
- 页面首屏直接输出正确的 `body` 类，避免先显示经典样式再切换造成闪烁。
- 如果现有启动脚本会提前应用主题、字体或动画，也应同步识别外观模式。
- 切换外观不得改变颜色主题、字体、字号、动画强度或数据列表偏好。

## 7. 兼容与边界

- 不修改业务页面结构、表单字段、权限或数据行为。
- 不删除现有主题和经典视觉。
- 不复制参考图片中的文字、人物、图标或具体业务布局。
- 不把所有元素强制改为胶囊形；密集数据页面保持可读性和操作效率。
- 不在顶部工具栏增加快捷切换入口。
- 不因圆润效果降低错误提示、危险操作或焦点状态的辨识度。

## 8. 测试与验收

### 8.1 自动化检查

- 设置模型可以保存并读取 `Classic` 和 `RoundedSoft`。
- 非法外观值回退到 `Classic`。
- 页面 `body` 同时输出颜色主题类和外观类。
- 设置页存在两张外观预览卡和正确的表单字段。
- 圆润外观 CSS 覆盖卡片、弹窗、控件、按钮、表格容器、菜单和导航核心选择器。
- 现有主题、字体、动画和全局设置测试继续通过。

### 8.2 人工检查

- 默认、清透玻璃、薰衣草奶油分别与两种外观组合检查。
- 项目、员工、财务、设备、导入导出、设置和登录页面检查。
- 高级筛选、快速编辑、下拉菜单、列选择和导出菜单检查。
- 桌面和窄屏检查，确保无横向溢出、遮挡或圆角裁切错误。
- 经典模式与改造前视觉保持一致。

## 9. 验收标准

- 用户能在系统设置页切换并保存“经典紧凑 / 圆润柔光”。
- 刷新、登录和页面跳转后外观保持一致，无明显样式闪烁。
- 所有主要卡片、弹窗、控件、按钮、菜单和表格容器在圆润模式下形成统一视觉语言。
- 所有现有颜色主题均可搭配圆润模式使用。
- 经典模式保留现有样式和布局。
- 完整测试与 Release 构建通过，服务启动和关键页面检查正常。
