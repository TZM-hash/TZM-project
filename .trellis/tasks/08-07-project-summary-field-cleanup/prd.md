# 清理项目金额与清单项数量冗余展示

## Goal

统一项目经营层的金额口径，避免把同一份由工程量明细计算出的金额拆成“预计金额”和“已结算金额”重复展示；同时移除项目管理中不参与业务决策的清单项数量展示。

## Requirements

- 项目层保留合同金额、当前工程金额、结算状态和合同数量；删除预计金额、已结算金额和清单项数量字段的项目层展示与输出。
- 当前工程金额继续由现有工程量明细的工程量与单价自动计算，计算公式、筛选、排序、收付款/开票口径保持不变。
- 项目详情中的工程量明细仍保留暂估/结算口径切换、工程量编辑和小计计算能力；不删除工程量明细本身或其数据来源。
- 项目列表列管理、项目清单导出、项目经营汇总工作簿和相关字段映射同步移除上述冗余字段。
- 项目详情“工程量明细”标签不再单独显示清单项数量；工程量明细表仍正常展示。
- 与项目汇总无关的财务收付款、设备累计结算等同名指标不改；不新增数据库迁移，不修改已有数据。

## Acceptance Criteria

- [ ] 项目管理列表只展示合同金额、当前工程金额及其他现有业务字段，不再出现预计金额、已结算金额、清单项数量。
- [ ] 项目列管理和项目清单导出选项不再提供上述三个字段，旧的已保存列配置不会使页面重新显示已删除字段。
- [ ] 项目经营汇总工作簿不再导出预计金额、已结算金额；项目工程量数据仍可正常导出/导入。
- [ ] 项目详情仍可编辑工程量明细的暂估/结算口径，当前工程金额计算结果不变。
- [ ] 相关领域、应用、导出和 Web 测试通过，并且代码中不再依赖项目汇总的冗余字段。

## Notes

- 当前数据库模型已经使用 `ContractLineItem.Quantity` 与 `UnitPrice` 作为统一工程量数据；历史的暂估/结算属性是非持久化兼容别名，不能在本任务中删除。
- 与 `CompanyDashboardDto`、`EquipmentDashboardDto` 等其他模块的金额字段需按实际消费情况区分，不因名称相同而误删独立业务指标。
