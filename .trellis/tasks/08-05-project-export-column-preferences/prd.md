# 项目清单独立导出列选择与保存

## Goal

让“导出项目清单”拥有独立于项目表格“列管理”的导出列选择，并按登录用户在服务器端保存选择结果。

## Requirements

- 保持现有项目表格“列管理”功能、显示结果和本地偏好不变。
- 在“导出项目清单”弹层中提供独立的导出列勾选区域。
- 导出 Excel 仅包含用户在导出区域中选中的列，并按该区域中的既定顺序输出。
- 导出列选择按登录用户保存到服务器；同一用户重新登录、换浏览器或换电脑后仍可恢复。
- 不同用户的导出列设置互不影响。
- 首次使用或尚未保存设置时，使用合理的默认导出列集合。
- 至少保留一列，避免生成没有业务列的项目清单。
- 继续沿用现有导出范围、排序、附件打包和权限规则。

## Acceptance Criteria

- [x] 调整表格“列管理”不会改变“导出项目清单”的列选择。
- [x] 调整导出列选择不会改变页面表格的可见列和顺序。
- [x] 执行导出后，生成的项目清单只包含所选列。
- [x] 导出列设置保存到服务器，并能被同一登录用户再次加载。
- [x] 其他登录用户不会继承该设置。
- [x] 未保存过设置的用户能看到默认列并正常导出。
- [x] 无法提交零列导出。
- [x] 现有勾选项目/当前筛选全部项目、排序和附件导出行为保持不变。

## Notes

- 保存范围已确认：按登录用户保存到服务器，而不是仅存当前浏览器。
- 优先复用现有 `SavedDataViews` 表并使用独立页面键，避免新增数据库迁移。

## Design

- 为项目清单导出定义独立的 `DataViewDefinition`，页面键使用 `projects-export`，与项目表格保存视图使用的 `projects` 完全隔离。
- 在该独立页面键下只保存一条当前用户的固定名称配置，`ColumnJson` 存储已选择的导出列键。
- 页面加载时读取当前用户的导出配置；没有配置时默认选中全部可导出列，始终排除 `actions`。
- 导出提交时按服务端允许的列集合过滤输入，并按标准字段顺序规范化；零列时拒绝导出。
- 合法选择先写入用户视图存储，再作为 `ProjectListColumns` 传给现有工作簿导出服务。
- 导出弹层提供独立复选框、已选数量、全选和恢复默认；不提供拖拽排序，Excel 使用标准字段顺序。
- 项目导出不再生成或使用 `data-export-column-key` 输入，因此不会参与 `data-table.js` 的共享同步；财务等其他页面继续保留该共享逻辑。

## Implementation Plan

1. 更新 `src/EngineeringManager.Web/Pages/Projects/Index.cshtml.cs`：
   - 定义独立导出视图键、固定配置名称和允许导出的列集合。
   - 页面加载时恢复当前登录用户的导出列设置或使用全列默认值。
   - 导出提交时规范化列、校验至少一列、保存配置，然后调用现有导出服务。
2. 更新 `src/EngineeringManager.Web/Pages/Projects/_ProjectWorkbookExport.cshtml`：
   - 将隐藏导出列输入替换为独立复选框列表。
   - 增加已选列数量、全选、恢复默认和服务器保存说明。
   - 将原“按列管理结果生成”文案改为“按下方独立选择生成”。
3. 更新 `src/EngineeringManager.Web/wwwroot/js/components/check-selector.js`，并检查 `data-table.js` 的共享逻辑：
   - 为项目导出列选择补充数量刷新和零列提交拦截。
   - 保留其他页面依赖的表格列同步，不给项目导出列生成同步属性。
4. 更新项目导出弹层相关 CSS，使列清单在桌面和窄屏下可滚动、易勾选，并保持现有弹层布局。
5. 更新 `tests/EngineeringManager.Tests/Web/ProjectListExportPageTests.cs` 和相关授权页面断言：
   - 断言导出列使用独立复选框与独立页面键。
   - 断言项目导出不参与共享同步，同时保留其他页面的同步实现。
   - 断言服务端保存、用户隔离和零列校验所需代码路径存在。
6. 定向验证：
   - 运行项目导出页面测试、项目授权页面测试和保存视图服务测试。
   - 构建 Web 项目。
   - 启动本地服务并通过健康检查验证服务可用；浏览器交互验证因当前浏览器没有登录态未执行，已由页面契约、完整测试和工作簿导出测试覆盖对应代码路径。

## Risks

- `SavedDataViews` 原本面向可命名视图；通过独立页面键和固定名称隔离，避免出现在现有项目视图列表中。
- 导出响应是文件下载，保存配置必须在生成文件前完成；若导出失败，已选择的列仍会保留，符合“选择后保存”的预期。
- 服务器端必须再次过滤列键，避免客户端提交未知列或空列。
