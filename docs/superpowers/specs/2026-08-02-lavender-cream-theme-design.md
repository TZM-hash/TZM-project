# 薰衣草奶油全局主题设计

日期：2026-08-02  
状态：待用户确认

## 1. 目标

在现有“科技商务”和“清透毛玻璃”之外，新增第三套可选的“薰衣草奶油”全局主题。主题参考用户提供图片中底层界面的紫白柔光、奶油白卡片、圆润边角和薄荷绿、粉色、天蓝点缀，不复制图片上的短视频大字、头像悬浮层或水印装饰。

主题只改变视觉材质，不改变页面结构、业务数据、权限、路由和交互行为。系统管理员可在“显示与交互设置”中即时预览并保存，保存后登录页及登录后的全部页面统一生效。

## 2. 已确认方案

采用“新增全局主题令牌”方案：

- 新增 `LavenderCream` 主题值和 `theme-lavender-cream` CSS 类。
- 通过现有 `--app-*` 设计令牌统一控制背景、表面、文字、边框、主色、状态色、圆角和阴影。
- 对侧栏、顶栏、导航、卡片、按钮、表格、表单、弹窗和提示等共享组件补充少量主题作用域样式。
- 继续使用现有 Razor Pages、SVG 图标、字体、动效和特效等级，不增加第三方依赖。

## 3. 视觉语言

### 3.1 色彩

- 页面背景：非常浅的薰衣草紫与奶油白柔和过渡。
- 主色：中等明度紫色，用于主按钮、选中导航、焦点和关键进度。
- 表面：奶油白或带轻微紫调的半透明白色。
- 点缀：薄荷绿表示成功，柔粉表示提醒或辅助强调，天蓝表示信息。
- 文字：深紫灰作为主文字，灰紫作为次要说明，确保业务表格长期阅读清晰。

### 3.2 材质与形状

- 共享卡片使用更圆润但不过度营销化的圆角。
- 阴影采用低对比、宽扩散的紫灰柔光，不使用厚重黑影。
- 边框使用浅紫灰或半透明白色，保持密集页面的区域边界。
- 侧栏使用更明显的薰衣草层次；主工作区保持高可读的浅色表面。

### 3.3 交互状态

- hover、focus、active、disabled 和校验错误继续沿用现有交互逻辑，只替换为本主题色彩。
- 主题兼容现有两套动效风格和三档特效等级，并继续尊重 `prefers-reduced-motion`。
- 焦点轮廓、状态徽章和文字对比不得只依赖细微颜色差异。

## 4. 系统集成

### 4.1 设置与保存

- `VisualTheme` 增加 `LavenderCream`，保留现有数值不变。
- `SystemDisplaySettings.ThemeCssClass` 映射到 `theme-lavender-cream`。
- 设置页新增第三张主题预览卡，选择后无需保存即可在当前页面即时预览。
- 保存仍写入现有 `Display.Theme` 键，不新增数据库表、字段或 Migration。
- 未知、损坏或旧版本无法识别的值继续回退到 `Default`。

### 4.2 全站覆盖

主题优先依靠令牌自动覆盖：

- 应用背景、侧栏、顶栏、底栏和导航状态。
- 面板、指标卡、表单区、工作台、工具栏和详情信息块。
- 主次按钮、输入框、选择框、标签、提示和弹窗。
- 表格表头、行 hover、选中状态、分页和排序控件。
- 登录、注册及公开首页中使用共享布局和组件的区域。

只对仍使用硬编码颜色、且在新主题下出现明显不协调或可读性问题的页面选择器做定向修正，不进行无关页面重构。

## 5. 文件边界

预计修改：

- `EngineeringManager.Application/Settings/SystemSettingsDtos.cs`
- `EngineeringManager.Web/Pages/Admin/Settings/Index.cshtml`
- `EngineeringManager.Web/wwwroot/js/pages/settings.js`
- `EngineeringManager.Web/wwwroot/css/themes.css`
- 必要时少量调整 `components.css` 或 `pages.css` 中的主题兼容规则
- 设置服务及前端资源相关测试

明确不修改：

- 数据库结构和 Migration
- 业务实体、核算逻辑、权限和路由
- 现有两套主题的名称与视觉
- 现有列表排序功能及当前未提交的相关改动

## 6. 异常与兼容

- 新主题保存失败时沿用设置页现有错误处理，不产生部分保存状态。
- 浏览器不支持 `backdrop-filter` 时，以实色浅色表面和阴影作为降级效果。
- 窄屏继续沿用现有侧栏抽屉和表格横向滚动，不增加新布局分支。
- 高对比、减少动画和键盘焦点行为不因主题切换而失效。

## 7. 验证

### 7.1 自动化

- 设置页面包含第三个主题选项和对应预览钩子。
- 设置服务可以保存、读取并审计 `LavenderCream`。
- CSS 包含新主题类及关键共享组件覆盖。
- JavaScript 预览类列表包含新主题，并能从其他主题正确切换。
- 运行设置相关定向测试与 Release 构建；公共逻辑受影响时再扩大测试范围。

### 7.2 视觉验收

- 在同一桌面视口检查登录页、系统总览、项目列表、包含表格和表单的代表页面、显示设置页。
- 对照参考图检查紫白层次、卡片圆角、柔光阴影和点缀色是否统一。
- 检查文字对比、表格边界、弹窗、hover/focus、侧栏折叠和窄屏状态。
- 保留本地服务运行，交付可直接打开的地址供用户查看。

## 8. 完成标准

- 设置页出现第三套“薰衣草奶油”主题并支持即时预览。
- 保存后全站稳定应用，刷新和重新登录后保持。
- 原有两套主题、动效、字体、字号和表格密度不回归。
- 不新增依赖和数据库迁移，相关测试及构建通过。
- 视觉效果明显体现参考图的柔和紫白主题，同时保持工程管理系统的信息密度和可读性。
