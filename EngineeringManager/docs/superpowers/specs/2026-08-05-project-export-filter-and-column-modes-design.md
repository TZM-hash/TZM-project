# 项目清单导出筛选与列来源设计

## 目标

让项目清单导出可以在导出窗口内独立设置项目筛选条件，并允许用户在“按列管理导出”和“按内容筛选导出”之间自由选择列来源。

## 交互设计

### 导出筛选

在“导出范围”下增加可折叠的“导出筛选”区域，复用项目高级筛选支持的字段：关键词、项目阶段、签约公司、项目负责人、负责员工、合作方式、当前工程金额最小值和最大值。

导出筛选默认沿用当前页面筛选值作为初始值，但使用独立字段提交；用户在导出窗口内修改筛选时不改变页面筛选。选择“当前筛选的全部项目”时，导出结果取导出筛选命中的全部授权项目。手动勾选项目时，仍以手动选择的项目为准。

### 列来源

在“导出内容”区域增加互斥的列来源选项：

- “按列管理导出”：提交页面当前列管理中可见的列；固定选择列不参与导出列切换。
- “按内容筛选导出”：提交导出窗口内独立勾选的项目清单列，并按当前登录用户保存。

默认保持“按内容筛选导出”，兼容现有行为。两种模式不能同时生效；切换模式时只切换来源，不清空另一模式的配置。

## 数据流与边界

页面模型将导出筛选转换为现有 `ProjectListQuery`，导出服务继续使用授权后的项目查询结果，不新增数据库表或迁移。列管理模式通过表格前端当前可见列生成提交字段；内容模式继续使用现有 `ExportColumns` 和用户视图存储。导出列最终由 `ProjectListWorkbookExporter` 做白名单归一化，防止客户端提交未知字段。

页面现有筛选、排序、分页和列管理行为保持不变；导出筛选仅影响本次导出。

## 错误处理

- 没有选择项目且未选择“当前筛选的全部项目”时，显示明确的导出范围提示。
- 导出筛选无命中项目时，显示“当前导出筛选没有可导出的项目”。
- 两种列来源均没有有效列时，显示“至少选择一列导出”。
